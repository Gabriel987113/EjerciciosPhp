5 ejercicios de arrays con planteamientos distintos.
1 Temperaturas: media, máximo, mínimo y clasificar valores.
2 Inventario: array asociativo, buscar código y modificar stock.
3 Liga: array multidimensional, calcular puntos y ordenar equipos.
4 Palabras: explode, contar repeticiones y obtener palabras repetidas.
5 Horario: array asociativo multidimensional, consultar un día y calcular huecos.
Cada ejercicio tiene una solución en index.php.
